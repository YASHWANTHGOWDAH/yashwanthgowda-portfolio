# Yashwanth Gowda H — Personal Portfolio

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run:
   npm install
   npm run dev
4. Open the local Vite URL shown in the terminal.

## Build for deployment
npm run build

The production files will be generated in `dist/`.

## Deploy
You can deploy the project to Vercel, Netlify, or GitHub Pages after running the production build.

## Replace later
- Add project screenshots under `public/` and link them from `src/main.jsx`.
- Add your email when you want a public contact email.
- Add more GitHub repositories after you publish them.
